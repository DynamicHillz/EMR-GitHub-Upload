# Old Scripts

This folder contains archived utility scripts that are no longer actively used but kept for reference.

## Contents

- Database setup scripts (various iterations)
- Enum fix scripts
- SQLite migration attempts
- Electron main files (from pre-implementation)
- Batch files for Windows
- Various database management utilities

## Note

These scripts were used during development and experimentation but have been superseded by:
- Prisma for schema management
- Current scripts in the `scripts/` folder
- Built-in npm scripts in package.json

**Do not run these scripts on production data** - they may be outdated or incompatible with the current schema.
